# Cube front (app/front.html)

Generated file. Do not edit app/front.html by hand.

1. `python3 tools/front/build_preview.py` writes the stand-alone preview (sample data).
2. `python3 tools/front/build_front.py` writes app/front.html, wired to the portal through window.ZFRONT_HOST (assets/portal.js).

The engine is sliced from zkj-system/index.html (the business-card cube). Icons: zkj-icons.json, made from the ZKJ ICONS v1.0 and ZKJ PLATFORM MARKS v1.0 (HEX) sprites by icons_from_sprites.py.

# Your Claude Skills & Workshop Materials — User Guide

Everything from your workshop folders (Desktop → ZKJ VERSE PROJECT AGAIN → Clauda) has been reviewed and converted into 3 installable Claude skills, summarized below. The two folders ("Clauda token saving" and "ملفات الورشة") contained mostly the same files.

## How to install the 3 skills

Each skill was delivered as a `.skill` file in this chat. Click **Save skill** on each card, or add them manually via **Settings → Capabilities → Skills**. Once installed, they work in every conversation automatically — you don't need to open any file.

### 1. map-video-prompts 🏛️
The viral "building rising from Google Maps" 3D video.

- **How to use:** just say *"make me a map video for [your building] in [city]"*.
- Claude fills your building and location into 3 professional prompts (2 images with Nano Banana Pro + 1 video with Kling 3.0) and gives you the full production steps for either Higgsfield or Gemini.
- You need 2 reference images ready: a photo of your building + a Google Maps screenshot.
- Output settings: 9:16 vertical, 5 seconds, pro mode, sound on.

### 2. reels-dashboard 📊
Instagram Reels analytics dashboard powered by Windsor.ai.

- **One-time setup:** connect Windsor.ai in claude.ai → Settings → Connected Apps, and link your Instagram (Business/Creator account only) inside windsor.ai via Add Connector.
- **How to use:** say *"analyze my reels"* or *"build my reels dashboard"*.
- Claude pulls your last 30 reels and builds a 5-tab interactive dashboard: overview KPIs, what worked vs what didn't, charts + best-posting-time heatmap, prioritized recommendations, and a data-driven 7-day content plan with ready captions.
- Pro tip from the guide: ask for it as a **Live Artifact** so it refreshes your Windsor data automatically every time you open it.

### 3. token-saver 💰
Save 60–90% of your Claude tokens.

- **How to use:** ask *"how can I save tokens?"* or *"audit my Claude usage habits"*.
- Contains all 12 golden tips (PDF→Markdown, Projects, separate chats, CSV over Excel, crop images, merge questions, checkpoint restarts, right model choice…), the image token formula (width×height÷750), and the model rule: **start Sonnet → Haiku if simple → Opus only if truly complex**.

## ⚠️ Content Engine (مكينة المحتوى) — action needed

The folder only contains the **usage guide PDF**, not the plugin itself. The guide says the download includes a `content-engine.plugin` file — that file is not in these folders.

- Find the original zip you downloaded (check your Downloads folder or the source where you got it — the creator's Instagram channel).
- Once you have `content-engine.plugin`, install it via **Settings → Capabilities → Plugins**.
- Usage per the guide: create a Project named "مكينة المحتوى", type **"مكينة المحتوى"** to open the news dashboard, pick a news card, send it to Claude → it becomes a 6-slide Instagram carousel in your colors and voice, exportable as PNG (1080×1350).

# Shopify Product Listing — ZKJ VERSE

## Title format

`<Artwork Name> — <Collection> Collection`
Example: `Obsidian Mind — Unknown Presence Collection`
Standalone pieces use the artwork name only (e.g. `Golden Roots`). Max 60 characters.

## Vendor field

- Unknown Presence pieces: `KJ VISION | ZKJ VERSE`
- Photography/Spectrum Burst: `ZKJ VERSE` or `KJ VERSE` per existing pattern — check the collection before creating.

## Description structure (in order)

1. **One-line hook** — the feeling of the piece, not specs.
2. **The story** — 2–3 sentences: inspiration, connection to Dubai/engineering/the collection narrative.
3. **Edition statement** — exact and factual: "Limited edition — only 10 pieces per variant will ever be produced." Include certificate/authenticity note if applicable.
4. **Specs block** — medium (acrylic / resin print / digital), dimensions per variant, finish.
5. **What's included** — print, NFT pairing if any, packaging.

## Pricing & positioning

- Premium brand: compare-at pricing is allowed (e.g. $456 → $380) but never language like "cheap", "sale ends soon", "last chance".
- Price anchors by tier: Unknown Presence prints ~$380; Spectrum Burst $650–850; flagship pieces $1,500+. Flag anything that breaks tiering for owner review.

## SEO fields (every product, no exceptions)

- Meta title: `<Title> | ZKJ VERSE` (≤60 chars)
- Meta description: 140–155 chars, includes medium + "limited edition" + Dubai/digital art keyword.
- Image alt text: describe the artwork visually ("surreal masked figure in prismatic purple light"), not "product photo 1".

## Collections

Assign every product to exactly one primary collection (Photography / Wall Art / Digital goods) plus its named collection (Unknown Presence, Spectrum Burst...). Nothing lives uncategorized.

## Don'ts

- Don't publish without all variant images uploaded and alt-texted.
- Don't invent edition sizes — confirm the real number with the owner.
- Don't write descriptions over 200 words; collectors skim.

# ZKJ Content Studio

Personal content-repurposing plugin for ZKJ VERSE. Feed it a YouTube video, post, or article — get an Arabic X thread and a 6-slide Instagram carousel in your brand voice and colors.

## Skills

| Skill | What it does | Say |
|-------|--------------|-----|
| setup-identity | One-time setup: saves your brand name, niche, dialect mix, colors, tone, and CTA to `ZKJ-IDENTITY.md` | «جهز هويتي» |
| make-thread | Turns a link or pasted content into a 5–10 tweet Arabic X thread (Gulf hook + MSA body + CTA) | «سوّ لي ثريد: [رابط]» |
| make-carousel | Turns the same content into a 6-slide 1080×1350 carousel HTML with one-click PNG download | «اعمل كاروسيل عن: [رابط]» |

## First use

1. Install the plugin.
2. Say «جهز هويتي» and answer the questions once.
3. Drop any YouTube link or post and ask for a thread or carousel.

Language default: MSA for information, Gulf dialect for hooks and CTAs.
